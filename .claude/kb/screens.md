## check.tsx `ScamChecker`
State local: text, images, checkState(status|result|error). `verdictCopy: Record<ScamVerdict,{label,advice,tone:StatusTone}>` likely_scam "This looks like a scam"/danger, likely_safe "This looks safe"/success, uncertain "Hard to say for sure"/warning.
- isLoading; hasInput = text.trim()||images.length; canSubmit = hasInput && !isLoading. useEffect announces verdict label / error (AccessibilityInfo).
- UI: ScreenIntro "Not sure about something?"/"Paste the message or add a screenshot, and we'll take a look." → Card{field(gap sm): bodyStrong "The message" + TextInput (typography.body, bg background, border 2 borderStrong, square, minH 160, placeholder textMuted, selection primary); horizontal square thumbs 140² (ScrollView bleeds -gutter, content px gutter) + tonal fullWidth "Remove"; tonal "Add a screenshot"(addPhoto)} → Inset{filled fullWidth "Check for Scam"(search); if !hasInput callout muted centered "Paste a message or add a screenshot first."} → Inset loading row ActivityIndicator + "Reading your message..." → error: InstructionStrip warning label "That didn't work" {error} (direct Screen child, full width) → success Card{title verdict label (role header) + callout "How sure we are: N%", explanation, InstructionStrip verdict.tone bleed {advice}, tonal "Check another"(refresh) reset}.

## quiz.tsx `Quiz`
State local (logic [[data]]). useEffect createQuiz on mount; announces "Correct."/"Not quite." when answered.
- ScreenIntro "Can you tell which ones are scams?"/"Read each message and decide if it's a scam." (header title is "Spot the Scam").
- preparing: centered Card ActivityIndicator large + muted "Getting your quiz ready...". prepared: Card title "{T} practice messages are ready" + blurb + filled "Start quiz"(play). error: Card{InstructionStrip warning bleed "That didn't work" {error} (generateQuizItem network msg "Check that you're online, then tap Try again.") + filled "Try again"(refresh)}. finished: Card title "You got {score} of {T} right." + perfect/encouraging line + "Play again"(refresh).
- current: Inset progress row bodyStrong "Question N of T" / callout muted "{score} right so far" + Meter(N/T). Card{bodyStrong "The message" + fixed square frame View(minH 120, p md, bg background) with text | expo-image width 100% aspectRatio}. asking: Inset gap lg (wide separation for tremor) tonal fullWidth "It's a scam"(flag) / "It's not a scam"(check). answered: Card{title "Correct."(success)/"Not quite."(danger), InstructionStrip bleed tone isScam?danger:success label "This was a scam"/"This was not a scam" {explanation}, filled "See my score"/"Next question"(arrow)}.
