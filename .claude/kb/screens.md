# screens (all default exports in app/(tabs)/)
Every tab: `Screen` (top bar) + `ScreenIntro` (except Home: hero header). Cards use `index` for stagger. Components: [[ui]]. Logic: [[data]].

## index.tsx `Index`
Inset hero (FadeInDown): Headline largeTitle "Know the signs before they reach" + accent "your door.", body "Paste a message or add a screenshot. We'll explain it plainly.", primary stretch "Start a check"(search) → `router.navigate("/check")`. Card(1){SectionLabel "The golden rule", headline "Before you reply to anyone", InstructionStrip warning gift-card/wire/crypto rule} → FeatureCard /quiz (quiz icon, "Spot the Scam", "Practice with 5 messages and see what gave each one away.") + FeatureCard /ai-scams (sparkles, "What AI scams look like", "How AI changed scams, and the signs that still give them away.").

## check.tsx `ScamChecker`
State local: text, focused, images, checkState(status|result). `verdictCopy: Record<ScamVerdict,{label,advice,tone:StatusTone}>` likely_scam "This looks like a scam"/danger, likely_safe "This looks safe"/success, uncertain "Hard to say for sure"/warning.
- isLoading; hasInput = text.trim()||images.length; canSubmit = hasInput && !isLoading. useEffect announces verdict label (AccessibilityInfo). Failures: no in-screen UI; handleSubmit catch → `console.error("Scam check failed:", caught)` + native Alert "Couldn't check that"/"Please check your internet connection, then try again." + reset to idle (form keeps input).
- UI: ScreenIntro label "Scam Checker" / lead "Not sure about something?" accent "Let's take a look." / "Paste the message or add a screenshot, and we'll explain it." → Card(1){TextInput (typography.body, bg surface, 1.5 borderStrong → primary when focused, radius 12, minH 160, placeholder textMuted); horizontal thumbs 140² radius 8 hairline (ScrollView bleeds -lg to card inner edges) + secondary stretch "Remove"; secondary center "Add a screenshot"(addPhoto)} → Inset{primary stretch "Check for Scam"(search); if !hasInput callout muted "Paste a message or add a screenshot first."} → Inset loading row ActivityIndicator + "Reading your message..." → success Card{title (tone = verdict.tone) verdict label, ConfidenceBar "How sure we are", explanation (tone text), InstructionStrip verdict.tone {advice}, secondary stretch "Check another"(refresh)}.

## quiz.tsx `Quiz`
State local (logic [[data]]). useEffect createQuiz on mount; announces "Correct."/"Not quite." when answered.
- ScreenIntro label "Spot the Scam" / lead "Can you tell" accent "which ones are scams?" / "Read each message and decide if it's a scam."
- preparing: centered Card ActivityIndicator large + muted "Getting your quiz ready...". prepared: Card title "{T} practice messages are ready" + blurb + primary "Start quiz"(play). error: Card{InstructionStrip warning "That didn't work" {error} + primary "Try again"(refresh)}. finished: Card title "You got {score} of {T} right." + StepChart(current null) + line + "Play again"(refresh).
- current: Inset bodyStrong "Question N of T" + StepChart (current = index while asking, null while answered). Card{bodyStrong "The message" + fixed frame View(minH 120, p md, radius 12, bg surface; text tone text) with text | expo-image width 100% aspectRatio}. asking: Inset gap lg secondary "It's a scam"(flag) / "It's not a scam"(check). answered: Card{title "Correct."(success)/"Not quite."(danger), InstructionStrip tone isScam?danger:success label "This was a scam"/"This was not a scam" {explanation}, primary "See my score"/"Next question"(arrow)}.

## ai-scams.tsx `AiScamsInfo`
ScreenIntro label "AI Scams" / lead "What's changed" accent "about scams lately." / "And what still gives them away." → one Card per `topics:{title,body,advice}[]` (voice cloning, fake photos/videos, fluent AI writing): headline + body + InstructionStrip success advice → Card{SectionLabel "The signs", title "What still gives it away" + body + InstructionStrip danger label "Stop if you see" (urgency/secrecy/gift card/wire/crypto)}.
